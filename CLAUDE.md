# Claude Code

Этот репозиторий — система авторской работы. Общая политика находится в `AGENTS.md`; локальный `AGENTS.md`, `project.json`, `START_HERE.md` и `book.json` выбранного тома уточняют контекст.

Для независимого литературного диагноза используйте `/ru-literary-editor`. Не открывайте отчёты ChatGPT/Codex или Gemini текущего прогона до фиксации собственного отчёта. Диагноз не даёт разрешения менять рукопись.

Для внесения уже принятых автором решений используйте `/ru-approved-revision`. Перед правкой прочитайте общий навык ревизии выбранного проекта и специфический навык серии. Не создавайте отдельный Claude-канон и не сохраняйте факты книги только в auto memory.

Запускайте Claude Code из корня репозитория, чтобы обнаруживались общие навыки в `.claude/skills`.

Действующая языковая система: [BOOK_SYSTEM](BOOK_SYSTEM/README.md). Новая проза украинская. Claude Opus обязателен в литературном цикле вместе с Gemini 3.8 Flash и Gemini 3.1 Pro; читать их отчёты можно только после фиксации собственного. Для адаптации использовать `/literary-adaptation`, для языковой сверки — `/book-language-review`. Если Opus сам создавал адаптацию, его вычитка не называется независимой; двуязычную QA выполняет Sol.
