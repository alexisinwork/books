# Схема книжного проекта, версия 1

Логические пути ниже не требуют создания пустых папок или переименования существующих файлов.

| Область | Содержимое | Обновление |
|---|---|---|
| project/manifest.json | ID проекта/тома, стадия, мастер, SHA-256, основание выбора | При смене мастера |
| series/canon | Правила, ограничения, глоссарий, доказательства | После принятой правки текста |
| series/intent | Будущие тома, альтернативы, вопросы | При планировании |
| book-01/plan | Обещание, арки, сцены, карта раскрытий | До и в ходе черновика |
| book-01/manuscript | Единственная редактируемая главная версия | По принятым правкам |
| book-01/derived | Поисковое извлечение, метрики, хеш мастера | Перегенерировать после мастера |
| book-01/audit | Находки, сцены, часы, люди, вещи, знания | По проверенному тексту |
| book-01/feedback | Дословные отзывы, версия чтения, решения | После сверки отзыва |
| book-01/release | Читательский файл, хеш, итог проверок | После проверки выпуска |
| book-01/end-state | Подтверждённое состояние в финале | По фактическому финалу |
| archive | Старые версии с явным статусом | При замене мастера |

## Записи

Все записи: project_id, book_id, source_sha256. Якорь: chapter_id + paragraph_id + quote. Номер абзаца действует только для одного хеша; после правок заново привязать доказательства.

Находка: id, category, severity, certainty, anchors[], observation, reader_effect, proposed_change, dependencies[], verification, decision. severity: critical/major/minor/optional. certainty: text_conflict/missing_link/interpretation/preference. decision: proposed/accepted/rejected/applied/verified. Применение и проверка — разные состояния.

Сцена: ID, POV, место, время, цель, препятствие, решение, результат, цена, связь со следующей, изменения состояния. Не требовать одинакового состава соседних глав при смене POV или времени.

Знание: fact_id, носитель, known_from, источник, доступность читателю, степень уверенности. Знание, догадку и ложь различать.

Количество: сущность/группа, единица, начало, поступило, выбыло, конец, входит_в_группу, время, источник. Экипаж отделять от пассажиров; спасённых с планеты — от оставшихся в колонии.

Время: событие, точка отсчёта, относительное/абсолютное время, длительность, дедлайн, допущение. Общий дедлайн и локальное окно прохода вести отдельно.

Мотив: форма, появления, функция каждого, изменение значения, отдача, решение. Повтор образа допустим; повтор объяснения уже понятого вывода часто лишний.

## Работа и выпуск

Замысел → причинный план → черновик → структура → непрерывность → ясность и голос → корректура → читательский файл → актуализация канона. После структурных изменений повторять зависимые проверки.

Критерии: нет открытых critical; каждое major исправлено или осознанно оставлено; числа и знания сходятся; принятые правки подтверждены в повторно извлечённом итоговом файле. Чтение вслух, независимую бету и проверку вёрстки отмечать выполненными только при реальном выполнении. Новое объяснение обозначать предложением, а не найденным фактом.
