# Рабочие скиллы

Пять самодостаточных папок: architect — устройство проекта; writer — текст сцены; voice — подача; auditor — проверка по источнику; revision — адресная правка. Полные имена начинаются с ru-book-. Внутри сохранены SKILL.md, references, assets, agents и инструменты, где они предусмотрены.

Это переносимые полные копии. Их можно передавать ИИ как инструкции вместе с файлами задачи. Установка зависит от поддерживаемой вашим приложением системы скиллов; наличие папки в GitHub или Drive само по себе не означает автоматическую установку.

Начинайте с нужного этапа и читайте references по необходимости. В запросе явно указывайте книгу и скилл. AGENTS.md и guides/SCHEMA.md связывают их с путями проекта. Содержимое пяти исходных рабочих папок сохранено без изменений; series-specific инструкции соседних проектов не наследуются чистым default.
