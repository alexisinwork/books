# Карта проходов

1. Читательский договор: жанр, обещание начала, завершение тома, вопросы серии. Крючок продолжения не заменяет развязку книги.
2. Причинность: цель → попытка → сопротивление → решение → последствие. Проверить очевидные альтернативы. Ошибка героя должна вытекать из убеждения или информации, а не из исчезнувшей способности.
3. Персонажи: желание, рана/страх, ложное убеждение, потребность, поступок с ценой, изменение поведения. Психология — литературная линза, не диагноз. Голоса различать по синтаксису, деталям, действиям, не только присказкам.
4. Непрерывность: люди, груз, вещи, ресурсы, география, часы, знания. Сравнивать связанные состояния с учётом POV, флешбэков и пропусков времени.
5. Твисты: факт, подсказки, альтернативное объяснение, узнавание героем/читателем, действие после. Различать интригу «кто» и «как/какой ценой».
6. Мир: возможности, пределы, цена, носители знания, социальные последствия. Объяснять механизм связи ресурса с политическими ставками.
7. Ритм: новое действие/сведение/выбор, повторы последствий, пауза после потери, осмысленное эхо и повторное разъяснение.
8. Язык: обломки конструкций, согласование, фокус восприятия, местоимения. Варианты вкуса — отдельно. Словарь проверяет конкретную модель, не запрещает метафоры вообще.
9. Выпуск: принятый список против итогового файла, повторное извлечение, обновлённый конец тома. Аудиочтение и вёрстка требуют отдельного выполнения.

Запись: id, source_sha256, chapter, anchors[{p,quote}], category, severity, certainty, observation, effect, proposal, dependencies, verification, decision.

critical ломает центральную причинность/раскрытие/развязку; major локально нарушает понимание; minor — буквальная ошибка; optional — вкус/плотность. Важность и уверенность — разные оси.
