# Перевірка нормативних тверджень рецензентів

Дата: 14.09.2026. Статус: `post_freeze_case_based_addendum`.

Це окрема перевірка п’яти конкретних підстав для правки, виконана після замороження INPUTS-V3 / ready-v3 перших двох оповідань та INPUTS-V4 / ready-v4 третього. [CREATED-INPUTS.json](../pipeline-work/native-inputs/CREATED-INPUTS.json) фіксує створення пакетів о 20:01:18 UTC; їхня вибрана версія NATURALNESS має SHA-256 `3f890bec3cbdce3a15e8ef72614d02108aa2370cd2ce217e76dc7a80817fae2e`. Цього доповнення в тих знімках немає. Воно не було контекстом уже завершених рецензій і не змінює їх заднім числом.

Координатор передав результати власної перевірки й доручив їх зафіксувати. Агент `uk_rules_update` повторно відкрив наведені джерела, перевірив сторінки обох PDF, SHA рецензій і точні входження цитат у заморожені цільові файли. Це перевірка тверджень, а не нове повне читання оповідань, авторське затвердження стилю чи канону. Позиції нижче розрізняють непорожню цільову одиницю та фізичний рядок TXT.

## 1. «Кисті рук»: анатомічне значення існує

**Твердження:** Fair Flash, S3 LANGUAGE, пункт 2, пояснює «кисті рук» як лексичну кальку, нібито українська «кисть» насамперед позначає ботанічні об’єкти або нитки. Перевірений фрагмент: «Кисті рук були акуратно прив’язані за спиною до стільця»; цільова одиниця 119, рядок 237, source ID `story-02-fair-killer-c000-p000126`.

**Джерела:** у відповідних статтях [СУМ-11](https://slovnyk.me/dict/sum/кисть) та [СУМ-20](https://slovnyk.me/dict/newsum/кисть), відкрито відтворених на Slovnyk.me, подано анатомічне значення: ділянка руки, що починається біля зап’ястя та охоплює пальці. Ілюстрація СУМ-20 містить і сполуку «кисті рук».

**Висновок:** нормативна підстава заборони спростована; статус лексеми в цьому значенні — `already_correct`. Можливість скоротити опис або точніше назвати місце зв’язування треба обґрунтувати окремо. Заміна на «долоні» чи «зап’ястки» не є нейтральною автоматичною заміною тієї самої частини тіла.

## 2. «Вичитуватиме нам»: давальний не заборонений

**Твердження:** Chaos Flash, дефект 1 (S3 LANGUAGE), називає «вичитуватиме нам» ненормативним керуванням і, посилаючись на СУМ-11, вимагає «нас» або іншого звороту. Цільова одиниця 4, рядок 7, source ID `story-03-chaos-logic-c001-p000005`.

**Джерело:** [СУМ-11, «вичитувати», значення 5](https://slovnyk.me/dict/sum/вичитувати) позначає вживання у значенні докору як перехідне й неперехідне. Приклади містять давальні форми «їй», «дружині», а також знахідну форму «сержанта».

**Висновок:** вимога лише знахідного відмінка спростована; щодо заявленого дефекту керування — `already_correct`. Інший вислів можна обрати за голосом та інтонацією сцени, але не на підставі цієї вигаданої норми. Керування інших значень дієслова перевіряється окремо.

## 3. «По секрету»: словникова реєстрація та стиль

**Твердження:** Fair Flash, S4 OPTIONAL, пункт 1, приписує «по секрету» відтінок суржику/кальки, водночас прямо допускає його в домашній розмові й не оголошує обов’язковим дефектом. Перевірена цитата «скажу тобі по секрету» — цільова одиниця 110, рядок 219, source ID `story-02-fair-killer-c000-p000115`. Отже, самому звіту не приписуємо категоричної заборони, якої він тут не містить.

**Джерело:** [СУМ-11, «секрет»](https://slovnyk.me/dict/sum/секрет) фіксує «під секретом» і, з позначкою рідшого вживання, «по секрету» для конфіденційного повідомлення.

**Висновок:** словник не підтримує автоматичного ярлика суржику; вибір у цій репліці — `contextual_style_choice`. Позначка рідшого вживання не встановлює сучасної корпусної частотності й не гарантує однакової доречності в усіх голосах.

## 4. Форми на «-чий»: загальна заборона не випливає з правопису

**Твердження:** Fair Flash, S3 LANGUAGE, пункт 1, узагальнює неприйнятність атрибутивних форм на «-ачий/-ячий/-учий/-ючий», розбираючи «з палаючим поглядом» (цільова одиниця 233, рядок 465, source ID `story-02-fair-killer-c000-p000245`). Chaos Flash, дефект 2, критикує «левітуючу колбу» (одиниця 91, рядок 181, source ID `story-03-chaos-logic-c002-p000095`), але окремо визнає ад’єктивовані лексеми; ці формулювання звітів не тотожні.

**Джерело:** [«Український правопис», офіційне видання 2026, §119, п.1.1а](https://mova.gov.ua/storage/app/sites/19/2026/rishennja-komisiji/01-03/sdm-ukrayinskii-pravopis-vidannia.pdf#page=130) передбачає активні дієприкметники теперішнього часу на «-чий», зауважуючи їхнє переважне прикметникове та іменникове використання; серед прикладів — «живучий», «квітучий», «лежачий», «стоячий». Перевірено друковану й фізичну сторінку 130, індекс PDF 129. SHA-256 завантаженого PDF: `e593956bfba6737d991a76fa86970db9c10a5cd7fd8895bae67f2b9a950c3a92`.

**Висновок:** загальну заборону всіх цих форм спростовано; конкретне словотворення, синтаксичну роль, сполучуваність і ритм треба оцінювати окремо. Це не автоматичне виправдання будь-якої нової форми. Координатор обрав синтаксичну перебудову двох наведених місць, не глобальний суфіксальний blacklist; у цьому журналі правки прозі не застосовуються. Зняття хибного аргументу не зобов’язує зберігати конкретну конструкцію.

## 5. «Островом Південний»: назва у ролі прикладки

**Твердження:** Sol, `sol-r1-rem-024`, пропонує змінити «між Мурманськом і островом Південний» на форму з «Південним», пояснюючи це обов’язковим узгодженням прикладки. Перевірено цільову одиницю 182, рядок 363, source ID `story-03-chaos-logic-c003-p000189`.

**Джерело:** [Л. П. Бугаєнко, А. П. Романченко, «Українська мова. Синтаксис» (2024), с.34, «Узгодження прикладки»](https://dspace.oneu.edu.ua/bitstreams/e5ae94db-fd34-4f82-a85f-68f7c3f17264/download#page=34). Посібник окремо розглядає назви міст/сіл/річок та збереження називного відмінка для назв островів у ролі прикладки. Це навчально-методичне джерело, не окрема норма §119 правопису. Перевірено сторінку 34, індекс PDF 33. SHA-256 PDF: `f5ddc5209e1f0bcc978ba1bc25c94c784336cf2ae2a31a58280b2ac74f6cf3d0`.

**Висновок і межа застосування:** за цим правилом координатор зберігає «островом Південний»; примусова правка rem-024 не має заявленої підстави, щодо неї — `already_correct`. Застосування правила саме до цієї назви є редакторським висновком за її синтаксичною роллю. Це не універсальна заборона відмінювати географічні назви, ужиті самостійно чи в іншій конструкції.
