# Русский исторический источник

Используется для уже существующих русских текстов и явных поручений на их исследование/корректуру. Новый роман по умолчанию создаётся на украинском. Русская версия сохраняется с исходным форматированием, SHA-256, статусом окончательности и происхождением.

Проверять естественность русского только при работе с этим источником. Не применять русские грамматические нормы к украинскому или английскому тексту. Не обновлять RU_SOURCE_MASTER правками из адаптации и не делать обратный перевод новым оригиналом.

Исходная ошибка, неясный намёк или противоречие записываются отдельно. Исправление смысла требует авторского решения и собственной истории; языковая адаптация сама по себе не разрешает сюжетную редактуру.
