# Результат полного испытания RU→UK

Полные переводы всех трёх выбранных рассказов выполнены и подготовлены для чтения автором. Это проверка системы на 21 584 словах русского источника и 600 исходных непустых абзацах. Фрагменты вместо полных рассказов не использовались.

## Что испытано на рукописях

Подготовлены отдельные профили, голоса, предлагаемые глоссарии, реестры смысла и состояния по ходу каждого рассказа. Все входы заморожены; оригинальные DOCX сохранены побайтно. Переводы Sol привязаны к каждому исходному абзацу. Независимые отчёты Astra включают полное двуязычное чтение и отдельное чтение только украинского текста. Координатор сопоставил замечания с источником; исправленные версии сохраняют точное «было — стало».

Все три DOCX собраны с исходными стилями, абзацным оформлением и выделениями. Текстовое извлечение сверено с переводом; PDF используется для контроля рендера, страницы просмотрены. Подробные результаты привязаны к SHA-256 в `draft-vN/final-checks.json` каждого рассказа. Отдельное HTML-сравнение показывает весь русский и украинский текст, а не выборку примеров.

## Что пришлось исправить в системе

1. Поддержка рассказов без заголовков глав: явная глава 0, без выдуманных глав или новых исходных ID.
2. Подсчёт слов теперь включает исходный текст до заголовков и рассказ без заголовков.
3. Добавлен отсутствовавший `BOOK_SYSTEM/TOOLS.md`, на который ссылались рабочие инструкции. Эти общие изменения уже вошли в базовую ветку мастерской.
4. Экспорт DOCX учитывает вложенные `w:sdtContent` из Google Docs. В «Убийце» внутри таких элементов находились разделители и целый абзац реплики; теперь они сохраняются.
5. Смешанные курсивные и полужирные выделения переносятся по точным фрагментам перевода; первый выделенный run не окрашивает весь абзац.
6. Языковой сканер учитывает украинские апострофы. Нормативное «з’являється» больше не отмечается как отдельная калька «являється».

Свидетельство технических тестов — `technical-tests-v2.json`: 13 тестов инструмента литературного перевода и 4 языковой системы, все прошли. Проверки DOCX дополнительно выполнены на реальных документах. Это подтверждает указанное техническое поведение, а не качество всей прозы.

## Доступность моделей и предел результата

| Роль | Фактически выполнено |
| --- | --- |
| Sol | Три полных перевода и локальная редактура по сведённым замечаниям; временный writer пилота |
| Astra | Три полных двуязычных чтения, три отдельных target-only чтения и сверка изменений; точный охват версий указан в оценках QA |
| Opus | Полный двуязычный литературный отчёт только на первый черновик «Рептилоїдів» |
| Gemini Flash | Запрос отклонён настроенным OAuth-клиентом до обращения к модели |
| Gemini Pro | Запрос отклонён настроенным OAuth-клиентом до обращения к модели |

После первого успешного чтения Opus клиент сообщил об исчерпанном лимите сессии. Запрос «Убийцы» и дополнительное target-only чтение короткого рассказа не произвели отчётов. Логи отказов сохранены; они не считаются рецензиями. Идентификатор фактически вызванной модели Opus подтверждён журналом, дополнительный учёт Haiku в клиенте не означает ещё одного редакторского прохода.

Система довела весь выбранный объём до проверяемых рабочих файлов. Полная обязательная литературная проверка всеми назначенными моделями остаётся незавершённой. Глобальный PRIMARY, авторские решения по неоднозначностям и статус UA_CANONICAL_MASTER не назначены. Для продолжения полного выпускного цикла нужны доступные Opus/Flash/Pro и новые чтения точно выбранных итоговых файлов; прежние отчёты нельзя приписывать новым хешам.
