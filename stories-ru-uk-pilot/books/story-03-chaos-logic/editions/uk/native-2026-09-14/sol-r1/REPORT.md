## Механічні перевірки

Перевірки виконано на замороженому target з хешем `c21829136dd1240b6f6169dee9b76aca71978295fcb0eabe52f9c5af6bade8f2`.

- JSON усіх артефактів розбирається без помилок.
- 310 source-сегментів = 310 translation-блоків = 310 непорожніх абзаців target.
- Порядок `source_id` збігається з ready-v3, усі ID унікальні.
- Текст, відновлений із `translation.json` через подвійну межу абзаців, побайтово збігається з `target.uk.txt`.
- Рівно шість заголовків стоять на вихідних якорях `p1`, `p83`, `p169`, `p208`, `p269`, `p301`.
- Російських специфічних літер `ы/э/ё/ъ` не знайдено.
- `Ave, kháos!` трапляється один раз у фінальному блоці.
- Початковий `language_qa.py` дав `no_configured_signals`; його охват обмежений кількома механічними шаблонами й не є доказом якості.
- Початковий `uk_naturalness.py` дав один сигнал `literal_profanity` для `Твою матір!` (`story-03-chaos-logic-c001-p000075`). Після контекстного читання формулу залишено: це короткий емоційний вигук Гаррі під час аварії, він відповідає грубості джерела й не змінює адресата. Інструмент прямо позначає такий сигнал як контекстний, а не нормативний вирок.

Вихід `language_qa.py` рахує 619 текстових одиниць через порожні рядки між 310 абзацами, тому структурний охват перевірено окремо за JSON-вирівнюванням.
