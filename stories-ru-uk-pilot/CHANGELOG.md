# Изменения комплекта

## 1.0 — 2026-09-12

Первый переносимый комплект. Добавлены отдельные профили книг, явный мастер и контроль его хеша, шаблоны фактов и отзывов, пять рабочих скиллов, локальные инструменты, инструкции для Drive и GitHub. Система допускает fiction, nonfiction и memoir. Литературные метрики остаются подсказками для чтения.

## 1.1 — 2026-09-12

Переход на обычные файлы в четырёх каталогах default, buro, kontakt, riokka. Добавлена полная неизменная копия исходной системы, её поисковые проекции и карта применения. Новый new-project создаёт чистые независимые проекты; new-book откатывает незавершённую папку при сбое записи манифеста. doctor проверяет согласованность ID канона, prepare_repository переносит четыре проекта, verify_package принимает явный манифест. Дополнены тесты изоляции, переноса и отказов. Пять рабочих скиллов сохранены без изменений.

## 2026-09-14 — полный пилот RU→UK

Переведены целиком три авторских рассказа: 21 584 исходных слова, 600 непустых абзацев. Сохранены оригиналы, входные пакеты, версии Sol, независимые двуязычные и изолированные украинские отчёты, точные журналы исправлений. Финальный читательский пакет содержит 3 DOCX на 105 страницах и полное сравнение RU–UK.

Обнаружены и исправлены технические проблемы рассказов без глав, подсчёта слов, вложенных элементов Google Docs, переноса выделений и языкового сканера. Реальные ограничения Opus и Gemini записаны в отчёте готовности; обязательные невыполненные проходы не объявлены завершёнными. Неоднозначности исходников оставлены автору, украинский канон не назначен.
