# Архитектура живой книги

Определить проект и выбранный язык; по умолчанию `uk`. Прочитать общий [CORE](../../../BOOK_SYSTEM/CORE.md), [WRITING](../../../BOOK_SYSTEM/WRITING.md), локальные инструкции и профиль книги. Применить проектный `ru-book-architect` как совместимый с украинским исторический ID, затем правила серии.

Astra проектирует всю книгу на уровне конфликта, арок, крупных поворотов, тайн, подготовки/отдачи и финала. Детализировать только ближайшие 3–5 глав, оставляя место открытиям при письме. План и альтернативы сохранять отдельно от фактов готового текста.

Передать Sol конкретные scene briefs, состояние перед сценой, правила языка, голоса и настоящие авторские примеры. После написанного блока прочитать результат, сопоставить с архитектурой, проверить зависимости и обновить следующий блок в пределах поручения. Не выдумывать отчёты Opus/Gemini; завершение литературного цикла определяется REVIEW.md.

Для готового legacy-романа не проектировать новую историю под видом перевода: использовать `literary-adaptation` для переноса существующего авторского замысла.
