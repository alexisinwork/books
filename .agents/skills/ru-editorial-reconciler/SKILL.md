# Сведение независимых отчётов

1. Прочитайте `run.json` и выполните `python3 tools/editorial_ensemble.py verify --run PATH`. Начинайте сведение только когда отчёты `astra`, `claude` и `gemini` имеют статус `locked`.
2. Прочитайте три отчёта и проверяемый текст в точных местах. Не решайте спор голосованием моделей: одинаковая формулировка может иметь общий источник, а одиночное наблюдение может быть сильнее совпадения.
3. Объединяйте находки только при общей причине и общем диапазоне последствий. Сохраняйте ссылки на каждый исходный отчёт, позиции согласия и содержательные расхождения.
4. Для каждого пункта заполните `issue-ledger.json`: устойчивый ID, происхождение, категорию, серьёзность, уверенность, места, наблюдение, эффект, доказательства, варианты действия и зависимости. Оставьте `author_decision.status: pending`, `implementation.status: not_started`, `verification.status: not_run`.
5. В `reconciliation.md` расположите сначала решения, которые сильнее всего меняют книгу, затем локальные проблемы и сознательно отклонённый шум. Для спорных случаев сформулируйте автору один ясный выбор с последствиями вариантов.
6. Не меняйте канон, мастер или рабочую редакцию. Не обозначайте рекомендацию как `accepted` без явного ответа автора.
7. Удалите `<!-- FILL -->`, поставьте `Status: final` и выполните `python3 tools/editorial_ensemble.py record --run PATH --role reconciliation`.

Схема реестра и полный цикл: [EDITORIAL-ENSEMBLE.md](../../../EDITORIAL-ENSEMBLE.md) и `editorial/schemas/issue-ledger.schema.json`.
