# Независимый диагноз главного редактора

Язык берётся из выбранного издания; новая проза — украинская, английский оригинал — по явному выбору. Исторический ID `ru-` сохранён для совместимости. Прочитать [общий модуль](../../../BOOK_SYSTEM/README.md), CORE и целевой LANGUAGES. Литературный цикл обязательно включает Opus, Gemini 3.8 Flash и Gemini 3.1 Pro по REVIEW.md. Для схемы 2 `gemini_flash` и `gemini` — разные обязательные отчёты; сведение следует `run.json.required_diagnoses`. Старые прогоны схемы 1 неизменны.


1. Прочитайте корневой `AGENTS.md`, затем инструкции, `project.json`, `START_HERE.md` и `book.json` выбранного проекта. Откройте `run.json` указанного ансамблевого прогона и проверьте SHA-256 источника.
2. До фиксации своего отчёта не открывайте `claude-diagnosis.md`, `gemini-flash-diagnosis.md`, `gemini-blind-read.md`, `reconciliation.md` или заполненный `issue-ledger.json` этого прогона. Прежние аудиты используйте только когда автор прямо просит проверку относительно них; тогда проход уже не называется независимым.
3. Прочитайте весь заявленный текст. Для фактов и логики используйте относящиеся STYLE, канон, персонажей, хронологию, знания, ресурсы, обещания и переходы. Не подключайте другие серии.
4. Восстановите обещание книги, причинную цепь сцен, внешние и внутренние арки, решения и цену, подготовку и отдачу, ограничения противника и технологий. Отдельно проверьте числа, время, маршруты, состав групп и порядок получения знаний.
5. Для каждой существенной находки укажите точное место, наблюдение, читательский эффект, доказательство, уверенность, масштаб последствий и минимальный способ проверки. Отделяйте конфликт текста, недостающую связь, гипотезу и вкус.
6. Заполните `astra-diagnosis.md` текущего прогона. Сохраните сильные решения, полный охват и вопросы без ответа. Не редактируйте рукопись и не назначайте предложения каноном.
7. Удалите маркеры `<!-- FILL -->`, поставьте `Status: final` и зафиксируйте отчёт командой `python3 tools/editorial_ensemble.py record --run PATH --role astra`.

Полный порядок, имена файлов и границы ролей: [EDITORIAL-ENSEMBLE.md](../../../EDITORIAL-ENSEMBLE.md). Сведение выполняется отдельным навыком `ru-editorial-reconciler` только после всех обязательных зафиксированных отчётов.
