# Подлинные исходники

Здесь сохранены все 28 файлов доступной папки проекта, побайтно без редактирования. source-manifest.json хранит исходное имя, путь в архиве, фактический формат, размер и SHA-256. Имена путей приведены к Unicode NFC; содержимое не менялось.

Из шести романов только окончательный DOCX книги 1 явно выбран автором как главная версия. Остальные пять представлены найденными файлами, статус окончательности отдельно не подтверждён. MD книги 1 сохранён как другая версия.

Семь отдельных прозаических файлов с расширением .docx фактически являются UTF-8 текстом. Их исходные байты оставлены здесь, а в stories лежат читаемые .md-копии без притворного восстановления оформления Word.

ENTITY_STATE.yaml содержит проект «Разлад» (Марк Даль и другие персонажи). Он сохранён для полноты, но исключён из действующего канона Риокки. SERIES-BIBLE хранит намерения серии; при конфликте с утверждённым текстом требуется решение, а не автоматическая перезапись фактов.
