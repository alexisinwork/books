# Четыре исходных авторских скилла

alex-voice, alex-book-forge, alex-beta-reader и ru-line-editor скопированы целиком. Их SKILL.md сохранены побайтно. Новые пять рабочих скиллов находятся отдельно в skills.

У alex-book-forge подключены найденные references. sanderson-2025.md — копия исходного sanderson-2025-analysis.md. Три отсутствовавших материала получили явно подписанные новые шаблоны: библия серии, устройство серии и реестр ориентиров. Эти добавления не выдают себя за найденные старые разборы «Стальной Крысы» или 17 вселенных.

В исходниках есть частные предпочтения, биография и числовые ограничения для конкретного авторского проекта. Они не подключаются автоматически ко всем новым книгам. Сначала выберите, что нужно текущей задаче; при конфликте действуют инструкция автора и профиль книги. Старые скиллы не объявляются заново установленными только на основании копии в архиве.
