# Правила для Gemini (agy CLI) у проєкті «Ріокка»

## 1. Постійний контекст
- **Репозиторій**: `alexisinwork/books` (GitHub: `https://github.com/alexisinwork/books`).
- **Шлях серії «Ріокка»**: `riokka/` (`https://github.com/alexisinwork/books/tree/main/riokka`).
- **GitHub CLI**: `gh` авторизований (`alexisinwork`), доступ до GitHub репозиторію за замовчуванням.
- **Стан серії**: Томи 0–4 опрацьовані. Поточний активний том — **Книга 5 («Той, кого читають» / `book-05`)**.
- **Мова спілкування та матеріалів**: Завжди українська мова (`uk`).
- **Клієнт**: Тільки `agy CLI`, ніколи `gemini CLI`.
- **Обов'язкове дублювання на робочий стіл**: Після будь-яких перевірок, звітів чи опрацювання файлів — ЗАВЖДИ копіювати / дублювати всі результати на робочий стіл автора для перевірки: `C:\Users\alexi\OneDrive\Desktop`.

## 2. Літературна перевірка (Схема 2)
Обов'язкові 4 незалежні ролі на єдиному SHA-256 кандидата:
1. `astra` (Astra / Codex) — структура, причинність, арки, ресурси, обіцянки.
2. `claude` (Claude Opus) — проза, сцени, темп, емоційні вузли, голоси.
3. `gemini_flash` (Gemini 3.8 Flash) — повне текстове покриття, зв'язки, повтори, терміни, setup/payoff, якірні цитати.
4. `gemini` (Gemini 3.1 Pro) — ізольований холодний читач (blind reader).
