# Приоритет канона Риокки

Текущая инструкция автора → выбранный им мастер → доказанный факт этого текста → принятые межтомные решения → библия и ранний замысел. Новый файл по дате загрузки не старше содержания.

Книга1: авторский окончательный DOCX — основание аудита. Отдельная редакция создана по поручению автора; окончательное принятие новых механизмов ещё не записано. Остальные пять мастеров — найденные кандидаты.

WORLD описывает ранний замысел; «Справедливый убийца» — источник зерна канона, не автоматическая замена приквелу. Новый аутлайн Эсквайра не заменяет готовыйDOCX. ENTITY_STATE принадлежит Разладу и сохранён среди оригиналов только для полноты переноса.
