# Lore Bible — живая память рукописи (ENTITY_STATE)

Дополнение к series-bible-template.md. Библия серии — стратегия (арки, обещания, канон-правила); ENTITY_STATE — тактика: построчная база фактов, чтобы книга 7 не противоречила книге 2. Хранить как ENTITY_STATE.yaml в файлах проекта, обновлять после каждых 3–5 глав.

## Схема ENTITY_STATE.yaml

```yaml
characters:
  - name: "Лайт Винг"
    aliases: ["Эсквайр", "Лайти"]   # ловит баги типа Юля/Валя!
    appearance: "пепельные волосы, высокий лоб"  # цитатой из текста
    age_at: {книга1: 18, книга1_финал: ~30}
    skills: ["айкидо/карате", "все типы стрелкового", "пилотирование"]
    possessions: ["пистолет отца", "Глаза Хиггса"]
    wounds_scars: []                 # раны не исчезают между главами
    knows:                           # КРИТИЧНО: поток информации
      - {fact: "Хаст — отец Джулии", since: "гл.X", source: "ящик стола"}
    relationships:
      - {with: "Джулия/Кристина", state_by_chapter: {1: "жертва", 9: "союзник?"}}
    first_seen: "гл.1"
    status: "жив"                    # жив/мёртв/неизвестно + где изменилось

locations:
  - name: "Риокка"
    canon_facts: ["столица Кенари", "холм Розмари", "экосистема земного типа"]
    changes: [{what: "...", chapter: "..."}]

objects:
  - name: "чикайоки"
    rules: "пешка-убийца назначается заранее; ход через одну фигуру по вертикали"
    symbolic_load: "скрытая пешка = тема книги"
    location_now: "дом Вингов"

world_rules:
  - rule: "двигатели не запускаются при человеке рядом; ДНК капитана в бортовом ИИ"
    established: "гл.X"
    exceptions_allowed: false        # нарушение = сюжетное событие, не ляп

timeline:
  - {event: "гибель Накима Винга", when: "Лайту ~17", revealed: "гл.X", who_knows: ["Лайт", "Кирва"]}

open_threads:                        # висящие нити
  - {thread: "судьба матери Джулии", opened: "гл.2", status: "open", planned_payoff: "том 2"}
```

## Пять проходов извлечения (при аудите каждых 3–5 глав)

1. **Персонажи:** имена/прозвища/внешность/возраст — грепом по всем вариантам имени (урок «Космоса»: Юля/Валя/Валентина в одном тексте).
2. **Время:** дни недели, сезоны, «через три недели», даты бортжурнала — сходятся ли.
3. **Сущности мира:** локации, организации, техника — против canon_facts.
4. **Объекты:** кто чем владеет, где предмет сейчас, не телепортировался ли.
5. **Поток знаний:** для каждой реплики-ссылки на факт — «откуда он это ЗНАЕТ?» Персонаж не может знать раскрытое читателю, но не ему.

## Правила ведения

- Новая запись — только с указанием главы-источника.
- Конфликт двух записей = баг или намеренный твист; решить явно, пометить.
- Канон только добавляется; переопределение — с пометкой «канон-ревизия» и причиной.
- Перед написанием главы N — прочитать срез ENTITY_STATE по участвующим персонажам.
