# Как использовать найденные методики

| Исходник | Практическая роль | Ограничение |
|---|---|---|
| lore-bible.md | Требования к фиксации мира и непрерывности | Не готовый доказанный канон каждого тома |
| ENTITY_STATE.yaml | Пример сложного состояния серии | Фактически другой проект «Разлад» |
| twist-engine.md | Возможные механизмы раскрытий | Твист не обязателен для каждой главы |
| character-arc.md, truby-22-steps.md | Способы исследовать выбор и конструкцию | Не все модели одновременно и не обязательные проценты |
| psychology-toolkit.md | Мотивы, давление, отношения и подтекст | Художественная эвристика, не диагностика человека |
| qa-readability.md, ru_readability.py | Сигналы для повторного чтения | Длина фразы и индекс не являются оценкой таланта |
| sanderson-2025-analysis.md | Авторский конспект о структуре, мире и обещаниях | Сохранён как предоставленные заметки; сверка всех лекций не заявляется |
| SERIES-BIBLE | Намерения и маршрут серии | Требуется согласование с фактическими концовками |

Сначала определите вопрос, потом откройте нужный модуль. Общий комплект не требует, чтобы каждая книга была иронической фантастикой с одинаково компетентным героем. Обновления в авторских исходниках при сборке не делались.
