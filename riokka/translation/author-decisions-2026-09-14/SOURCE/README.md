# Сохранённые русские исходники

Здесь побайтные копии трёх выбранных русских источников: авторский DOCX тома 1 и последние подготовленные к авторской вычитке редакции томов 2–3. Контрольные суммы и исходные пути — в [decisions.json](../decisions.json). Не редактировать эти файлы; для нового авторского исходника создавать отдельный снимок и перепроверять зависимости. Копия не является переводом и не назначает новый канонический мастер.
