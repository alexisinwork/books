# Чотири оповідання — фінальна українська редакція

Поточна видача після авторських відповідей 15.09.2026: **[release-06/readers](release-06/readers)**. [Підстава, сім рішень і перевірки](release-06/README.md). Попередній `release-05` збережено як історію редакторського проходу 14.09.2026.

1. Випадковий експеримент.
2. Історія.
3. Космос — не місце для живих.
4. Куди відлітають качки взимку.

Три автором названі остаточними настільні UK-DOCX імпортовано як основу нової читальної редакції; «Випадковий експеримент» перенесено з попередньої видачі без зміни. Джерела RU не змінено. Це чотири окремі оповідання, не перенесення чи затвердження канону романів «Ріокка».

[Імпорт і межі перевірок](release-06/DECISION_LOG.md) · [Підсумкова перевірка](release-06/verification.json) · [Маніфест видачі](delivery.json). Старий [підсумок редакторського проходу](RECONCILIATION.md) стосується `release-05`.

Порівняння «Було — стало» з авторськими настільними DOCX та з `release-05` знаходяться в `release-06/<story>/CHANGES-FROM-*.md`. Первинні RU/UK DOCX — у `stories/<story>/SOURCE`; нові побайтні настільні знімки — у `release-06/SOURCE`. Незалежні звіти й точний обсяг читання — у `release-06/<story>/reviews-r*`.

Сім прямих відповідей автора й залежні для них місця синхронізовано. Сюжетні умовності, індивідуальні голоси й навмисна неоднозначність збережені. Число абзаців, словниковий скан і хеші не підтверджують художньої якості самі по собі; [ширші незняті зауваги](release-06/REVIEW-RECONCILIATION.md) не внесено голосуванням моделей.

Копія для читання на робочому столі Windows: `Оповідання — українська редакція після відповідей — 2026-09-15`. Зміни автора у читательській копії слід імпортувати новою редакцією зі зіставленням, не замінювати мовчки архівні джерела. Проміжні release-01–05 не використовувати замість release-06 для поточного читання.
