# Українські оповідання — імпорт авторських фінальних DOCX

Читальні файли: [«Випадковий експеримент»](readers/Випадковий%20експеримент.docx), [«Історія»](readers/Історія.docx), [«Космос — не місце для живих»](readers/Космос%20%E2%80%94%20не%20місце%20для%20живих.docx), [«Куди відлітають качки взимку»](readers/Куди%20відлітають%20качки%20взимку.docx). PDF кожного лежить у `<story>/render/`.

Три настільні DOCX автор назвав остаточними й вони побайтно збережені в `SOURCE/`; четверте оповідання перенесено без зміни з `release-05`. Сім відповідей — [AUTHOR_INTENT.md](AUTHOR_INTENT.md) і [заповнений список](Питання%20до%20автора%20%E2%80%94%20відповіді.md). Конкретні редакторські висновки відокремлено в [MEANING_LEDGER.json](MEANING_LEDGER.json). Точні порівняння «було — стало» з настільним файлом і `release-05` є для кожного оповідання; [журнал](DECISION_LOG.md), [перевірка](verification.json), [звірка звітів](REVIEW-RECONCILIATION.md), [запис доставки GitHub](GITHUB-DELIVERY.json).

Це автором обрані читальні українські версії після імпорту відповіді. Статус `UA_CANONICAL_MASTER` для подальшого EN не призначався. Науковий механізм миттєвого поштовху в «Космосі» й кілька ширших літературних питань збережено як відкриті в `../audit/issues.json`.
