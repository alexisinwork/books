# Рассказы и отдельная проза

Семь найденных файлов сохранены полностью. В этой папке их текст доступен под расширением .md; подлинные исходные имена и байты — в sources/originals.

Принадлежность каждого текста к действующему канону Риокки не подтверждается одним соседством в папке. В частности, отдельный «Справедливый убийца» не отождествляется автоматически с романом «Эсквайр», хотя во вступлении романа это словосочетание названо внутримировым названием. Связи устанавливаются отдельным сравнением и решением автора.
