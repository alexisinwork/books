# Робочий глосарій RU→UK

Статус наведених форм — `locked` у межах цієї редакції, якщо контекст не вимагає іншого.

| RU | UK | Примітка |
|---|---|---|
| васильки (квіти) | волошки | Не `васильки`: в українській це інше слово. |
| общага | гуртожиток / гуртяга | Повна й розмовна форма за голосом. |
| гравибол | гравібол | Вигаданий спорт. |
| грави-троллейбус | гравітролейбус | Узгоджена вигадана назва. |
| Дум / Симс / Цива | «Дум» / «Сімс» / «Цива» | Назви й коротка форма гри збережені. |
| Иван / Ваня | Іван / Ваня / Ваню | Форма залежить від оповіді та звертання. |
| Гоша | Гоша / Гошо | Кличний у звертанні. |
| Маша | Маша / Машо / Машко | За інтонацією репліки. |
