# Рабочие скиллы

Пять самодостаточных папок: architect — устройство проекта; writer — текст сцены; voice — подача; auditor — проверка по источнику; revision — адресная правка. Внутри сохраняются SKILL.md, необходимые ссылки и инструменты.

Это переносимые копии. Их можно передавать ИИ как инструкции вместе с файлами задачи; установка зависит от поддерживаемой вашим приложением системы скиллов. Само наличие ZIP или папки в Drive не означает автоматическую установку.

Начинайте с подходящего этапа и читайте references только по необходимости. В первой строке запроса полезно явно указать нужный скилл и книгу. AGENTS.md связывает их с путями этой сборки.
