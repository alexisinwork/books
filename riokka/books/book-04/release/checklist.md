# Проверка читательского выпуска

- [ ] Зафиксированы файл, версия и SHA-256.
- [ ] Нет нерешённых критических замечаний; по крупным есть явное решение автора.
- [ ] Принятые изменения проверены в итоговом файле, а не только в черновой копии.
- [ ] После структурных правок сверены зависимые знания, время, вещи и числа.
- [ ] Проверены орфография, имена, термины и оформление прямой речи.
- [ ] Визуально просмотрен экспорт: страницы, курсив, отбивки, заголовки, переносы.
- [ ] Реальные бета-чтение / чтение вслух отмечены только если выполнены.
- [ ] End-state соответствует фактическому финалу.
- [ ] В release.json указаны дата, основание выпуска и оставленные особенности.
