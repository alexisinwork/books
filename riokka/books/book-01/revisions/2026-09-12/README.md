# Редакция после аудита

revised.docx создан из окончательного авторского DOCX, который прочитал брат. 204 исходных абзаца изменены; исходные 1243 позиции сохранены. Оригинал остаётся в manuscript/master.docx и sources/originals.

Полный журнал: ALL-CHANGES.md; точный diff: all-changes.diff; проверяемые замены: patches.json. Изменения внесены, но новые сюжетные решения не объявлены окончательно принятым каноном.

Важные решения: независимое разведение сортов как политическая сила прариокки; окно 84 ч с 48 чперелётом; источники знания Джулии; материальная угроза приёмного сектора; итог 52 поселенца.

После авторской приёмки выбрать revised.docx командой set-master и обновить snapshot, состояния и доказательства. До приёмки context по умолчанию открывает прежний выбранный источник; для работы именно с редакцией указывать этот путь явно.
