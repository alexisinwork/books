# Холм Розмари — глоссарий ru-uk

Начальная машинная карта: riokka/translation/preparation-2026-09-14/glossary.json.
Исходная версия этой книги: riokka/books/book-03/manuscript/master.md; SHA-256: 9c3e242da0d512b851531cf94c1941aae7eabb2f236ea19f409b6f139d0bf76d.

Все предложенные украинские и английские формы пока `proposed`. en-US — утверждённая норма, но не утверждение каждого имени. Для UK→EN сначала нужны реальные украинские якоря; русские номера абзацев нельзя выдавать за украинские.

Для каждого имени/термина фиксировать основную форму, разрешённые склонения/кличные формы, сокращение, регистр, контекст, недопустимые подмены и авторское решение. Слова «почерк», «источник», «рука», «чистый» не заменять глобально: они имеют разные функции. Название игры не превращать в известную земную игру без поручения.

После авторского выбора внести его в локальный glossary.json с доказательством. Изменение повторяющегося решения требует сверки всех зависимых мест; исходные предложения сохраняются в истории.
