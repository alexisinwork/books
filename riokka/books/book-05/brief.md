# Тот, кого читают

Выбранный кандидат сохранён без редактуры. Извлечено 60 разделов по шаблону глав; это структурный счёт, не результат полного литературного аудита.

Направление развития по серии: Встреча с тем, кто считает, и ответ именами вместо обезличенной графы.

Подача — предложение: Сведение обещаний; возвращать ранние образы изменённым действием.

Следующее действие: Закрыть реестр обещаний1–4, проверить пределы знания и цены финального выбора. Финальнуюкоду не подменять ранними вариантами библии.
