# Рабочий проход тома

1. Подтвердить выбранный файл из book.json.
2. Закрыть реестр обещаний1–4, проверить пределы знания и цены финального выбора. Финальнуюкоду не подменять ранними вариантами библии.
3. Составить сценовую карту по полному тексту: цель, противодействие, выбор, цена, изменившиеся знания.
4. Проверить связь с предыдущим принятым концом.
5. Применять изменения адресно с журналом; сначала причинность и канон, затем голос и строка.

Полный текст уже находится в manuscript; писать роман заново по этому плану не требуется.
