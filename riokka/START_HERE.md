# Начать работу с Риоккой

В архиве все 28 найденных исходников проекта: шесть романов, другая MD-версия первой книги, семь отдельных прозаических файлов, четыре авторских скилла и поддерживающие материалы. Дополнительно включены пять рабочих скиллов, шаблоны, инструменты и три предыдущих редакторских результата.

1. Откройте series/book-matrix.md — это каталог шести романов.
2. Для первой книги откройте [страницу текущего финала](books/book-01/README.md), затем `books/book-01/book.json`. Выбранный автором мастер — `manuscript/master.docx`, SHA-256 `2651e6b7…`; пути файлов книги относятся к `books/book-01/`.
3. Финальная повторная проверка после ручного переноса лежит в `books/book-01/audit/final-2026-09-13-after-point-corrections/OVERALL.md`. Проверены 42 главы из 42 и все 250 страниц рендера; выпускной барьер пройден. Прежние мастера и редакция от 12 сентября сохранены как история.
4. Для другого тома сначала определите, является ли найденный файл окончательным. Затем выберите объём аудита или написания.
5. Для нового тома используйте new-book; для другого мира — отдельный чистый Boilerplate. Не копируйте всю Риокку в новый мир.

```sh
python tools/studio.py doctor
python tools/studio.py context --book book-01 --task "Выбрать правки по отзыву брата" --out sessions/book-01-next.md
```

В templates/book сохранён чистый образец. Предложения по разной подаче находятся в voice.json каждого тома; они не меняют текст и не утверждены автоматически. Исходные файлы неизменны и перечислены с хешами в sources/source-manifest.json.

Дополнительные проверки — [guides/REPOSITORIES.md](guides/REPOSITORIES.md). Единое хранилище — [SOURCE-OF-TRUTH.md](../SOURCE-OF-TRUTH.md), фактическое размещение — [DELIVERY-STATUS.json](../DELIVERY-STATUS.json).

Том 2: текущая редакция после рекомендаций Gemini — 402 687 знаков, 51 глава. Обновлены 13–14, 24 и 32; шесть лет Тимки подтверждены по авторскому мастеру книги 1. [Текст, DOCX, было—стало и проверки](books/book-02/README.md). Кандидат ожидает авторской вычитки.

## Украинский оригинал и языковые издания

Новый рабочий процесс: [BOOK_SYSTEM](../BOOK_SYSTEM/README.md), путь также задан в `project.json.book_system`. Новая книга создаётся на украинском; `new-book --language en` — явный английский оригинал. Русские файлы остаются историческими источниками. Для Риокки 1–3 сначала RU→UK, затем после авторского утверждения UK→EN; прямой RU→EN — отдельный зеркальный маршрут. Рукописи в ходе настройки системы не переводились. Литературный цикл требует Opus + Gemini 3.8 Flash + Gemini 3.1 Pro.
