# Работа с ИИ без потери контекста

В начале сессии сообщите ID книги, конкретную задачу, основную версию и допустимую свободу. Прикладывайте brief, voice, session и относящиеся к сцене страницы. Дальние тома подключайте для конкретной проверки, а не как постоянный фон.

Пример начала: «Прочитай AGENTS.md и books/my-book/book.json. Продолжи последнюю сцену по выбранному мастеру. Используй voice.json. Новые факты мира после текста вынеси в предложения. Сохрани POV и положение персонажей».

Для аудита: «Проверь причины решения в сценах X–Y по этому хешу. Для каждой проблемы дай короткую цитату, эффект и минимальную правку. Если это вкусовое предпочтение, назови его так».

Для подачи: «Сделай эту книгу более спокойной и наблюдательной. События и финал пробной сцены сохрани. Предложи профиль и один короткий образец; другие книги не меняй».

Завершение: обновить session.md, перечислить изменённые файлы и новые допущения. Отметить, какие решения принял автор, а какие остались вариантами. Сохранить следующий конкретный шаг.

Пакет context, создаваемый инструментом, — только стартовые файлы и указатели. Он специально не содержит полной рукописи и не даёт права утверждать, что книга прочитана. Перед цитированием нужно открыть указанный мастер или проверенное извлечение.
