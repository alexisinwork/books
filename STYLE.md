# Стиль мастерской

Перед художественным текстом выберите проект и прочитайте его правила стиля:

| Каталог | Стиль | Изменение сцен и проверка зависимостей |
|---|---|---|
| default | [STYLE.md](default/STYLE.md) | [Порядок работы](default/guides/SCENE-EDITING.md) |
| buro | [STYLE.md](buro/STYLE.md) | [Порядок работы](buro/guides/SCENE-EDITING.md) |
| kontakt | [STYLE.md](kontakt/STYLE.md) | [Порядок работы](kontakt/guides/SCENE-EDITING.md) |
| riokka | [STYLE.md](riokka/STYLE.md) | [Порядок работы](riokka/guides/SCENE-EDITING.md) |

Общий порядок подачи: текущая инструкция автора → согласованное исключение сцены → профиль книги → явно подключённые авторские черты → необязательный пресет. Этот файл задаёт маршрут; конкретные настройки хранятся в `voice.json` выбранной книги и не дублируются здесь.

Стиль не даёт права менять факты мира, биографию, способности или знания персонажей. При конфликте подачи с каноном зафиксируйте вопрос; при отсутствии нужного решения используйте статус `unresolved` по правилам проекта.

Система не навязывает всем сериям единый голос. Исторические примеры и материалы другой серии не становятся образцами текущей книги автоматически.

Языковое ядро: [BOOK_SYSTEM](BOOK_SYSTEM/README.md). Для новой прозы применять [украинский слой](BOOK_SYSTEM/LANGUAGES/uk/STYLE.md); для английского издания или явно выбранного английского оригинала — [английский](BOOK_SYSTEM/LANGUAGES/en/STYLE.md). Старые русские профили — свидетельства голоса, не обязательный синтаксис нового языка.
