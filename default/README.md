# Книжная мастерская default

`default/` — чистый рабочий шаблон для новой книги или серии. Рядом в общем репозитории находятся самостоятельные проекты `buro/`, `kontakt/`, `riokka/`. В каждом проекте книги получают собственные папки в `books/`, профили подачи, планы и выбранные основные файлы.

Начните с [START_HERE.md](START_HERE.md). Для начала достаточно замысла, профиля подачи, рукописи и заметки о следующем шаге. Остальные формы подключаются, когда помогают конкретной задаче.

В default сохранены пять полных рабочих скиллов, семь пресетов подачи, шаблон книги и исполняемые инструменты на Python 3.10+ без обязательных внешних зависимостей. `new-project` создаёт самостоятельную копию с новым ID и пустым состоянием, `new-book` — отдельный том внутри проекта. Существующие папки не заменяются.

Система из прежнего документа «Система работы с книгами» применена в структуре и рабочем цикле: [карта применения](guides/SYSTEM-APPLICATION.md). Исходный DOCX, его полный поисковый текст и контрольные суммы сохранены в `methods/history/`. Исторические примеры из него не включаются в канон новых книг.

Файлы хранятся обычным деревом каталогов. DOCX может оставаться основным текстом: производная копия для поиска и Git diff всегда связана с ним по хешу.
