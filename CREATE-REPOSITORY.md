# Создание приватного репозитория

Цель: `alexisinwork/book-writing-studio`, видимость Private. Содержимое подготовлено отдельными файлами в четырёх каталогах: default, buro, kontakt, riokka.

В текущем подключении доступны запись файлов, Git blobs, trees и commits, но нет операции создания репозитория. Проверка целевого имени не нашла существующий репозиторий. Поэтому удалённый репозиторий пока не создан.

Также GitHub-приложение обнаружено установленным на аккаунте bez4pieci, тогда как подключённый профиль — alexisinwork. Доступность публичных репозиториев профиля не доказывает доступ приложения к новому приватному репозиторию.

Остаточный шаг автора:

1. Открыть [форму создания](https://github.com/new?name=book-writing-studio&owner=alexisinwork&visibility=private), проверить владельца и Private, включить Add a README и создать репозиторий.
2. Предоставить подключённому GitHub-приложению доступ к этому репозиторию в аккаунте alexisinwork.
3. Передать ссылку на созданный репозиторий. После проверки владельца, приватности и доступа подготовленные файлы можно загрузить одним согласованным коммитом.

README при создании нужен для начальной ветки и родительского коммита. Существующие репозитории с другим содержимым для этой задачи не использовались. Этот документ фиксирует фактический остаток работы, а не просьбу заново подтвердить уже разрешённую загрузку файлов.
