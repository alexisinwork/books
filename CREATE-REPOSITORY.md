# Подключение к существующему репозиторию

Репозиторий уже существует: [alexisinwork/books](https://github.com/alexisinwork/books), основная ветка `main`. В нём находятся `default`, `buro`, `kontakt` и `riokka`.

Локальная рабочая копия в WSL — `/home/alexi/books`; её `origin` указывает на этот адрес. Содержимое Windows-папки `C:\Users\alexi\Desktop\writing-studio` было импортировано в него 12 сентября 2026 года. Прежняя инструкция создать `book-writing-studio` относилась к этапу подготовки и заменена фактическим подключением.

## Новая рабочая копия

На другой машине или в другой среде выполните в каталоге, где ещё нет папки `books`:

```sh
git clone https://github.com/alexisinwork/books.git
cd books
```

Для обновления существующей чистой рабочей копии:

```sh
git pull --ff-only
```

Перед отправкой изменений просмотрите diff и выполните проверки, относящиеся к задаче. Сохраните текст и все затронутые реестры/отчёты одним согласованным коммитом, затем отправьте его в `origin/main`.

## Версии и доступ

Основной текст книги задаёт её `book.json`; Git хранит файлы и историю. [Полная схема](SOURCE-OF-TRUTH.md), [первая книга Риокки](riokka/books/book-01/README.md), [инструменты проверок](riokka/guides/REPOSITORIES.md).

На 12 сентября 2026 года видимость репозитория — Public. Это описание фактического состояния; изменение доступа требует поручения владельца. Для неопубликованных рукописей рекомендуется приватное хранилище.
