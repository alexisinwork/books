# Книжная система: украинский оригинал и языковые издания

Действует по поручению автора от 14 сентября 2026 года. Новая художественная проза по умолчанию пишется на украинском (`uk`, не `ua`: UA — код страны). Английский оригинал (`en`) разрешается явным выбором для конкретной новой книги. Язык служебного разговора не определяет язык рукописи.

Два рабочих процесса используют одно ядро:

1. **Новая книга:** идея → архитектура всего романа → ближайшие 3–5 глав → украинский черновик → независимые литературные проверки → авторская редактура → `UA_CANONICAL_MASTER`.
2. **Языковая адаптация:** сохранённый исходник и его смысловые обязательства → литературная реализация на целевом языке → независимая сверка → чтение только целевого текста → авторская редактура → отдельное издание.

Для трёх старых русских книг: `RU_SOURCE_MASTER → UA candidate → UA_CANONICAL_MASTER → EN_EDITION`. Русский исходник сохраняется побайтно и доступен для последующей сверки. До явного утверждения украинского текста русский остаётся смысловой основой адаптации. После утверждения украинский имеет приоритет в английском издании; русская историческая версия не возвращает отменённые автором решения.

`project.json.book_system` указывает сюда. Активные навыки с историческим префиксом `ru-` теперь используют язык задачи и общий модуль: префикс сохранён для совместимости команд. Архивные навыки в `legacy-skills`, `methods/originals`, `sources/originals` описывают прошлую систему и не являются активной языковой политикой.

В общем репозитории поддерживается один экземпляр ядра. `new-project` переносит его версионированный снимок в самостоятельный проект; происхождение фиксируется в `SYSTEM-SNAPSHOT.json`. Снимок не обновляет уже созданную книгу молча. Языковой слой не диктует жанр, длину глав или обязательное число шуток.

Украинский маршрут испытан на трёх полностью переведённых рассказах: «Рептилоїди», «Справедливий вбивця» и «Логіка хаосу». Выполнены языковая редактура, проверки текстов и документов; выявленные проблемы внесены в общие правила. Охват конкретных моделей и ограничения внешних прогонов отражены в отчётах пилота. Это проверка процесса на этих текстах, а не сертификация новой книги или английского маршрута; каждое издание проходит собственный цикл.
