# Evidence extraction without adaptation

Read the exact source file identified by path and SHA-256. Do not translate or revise prose. Build the factual book bible, names/terms inventory, voice observations and meaning ledger using SCHEMA.md. Read chapters in order and track coverage; a search hit is not evidence that a whole chapter was read.

For each significant recurrence connect its occurrences with exact anchors and explain the changing function briefly. Track humour setup/payoff, ambiguity, intentional terminology errors, hidden information and possible foreshadowing. Record inferred links as model_hypothesis and leave unknown payoffs unresolved. Put only supplied, attributable author statements in AUTHOR_INTENT.

Distinguish master facts from plans and candidate revisions. In a multilingual legacy book do not merge evidence across versions without naming both sources. Do not invent English/Ukrainian names as already approved. Propose terms with context, inflection/address considerations and dependencies.

Output source-bound records, a concise coverage report and targeted author questions. Preserve uncertainty and note missing source state. No adapted prose and no fabricated gold examples.
