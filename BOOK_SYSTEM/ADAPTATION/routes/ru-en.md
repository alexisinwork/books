# RU → EN: зеркальный модуль по отдельному поручению

`source_language: ru`, `target_language: en`, `source_role: RU_SOURCE_MASTER`, `target_role: EN_EDITION_FROM_LEGACY_RU`. Подготовлен по просьбе автора продублировать систему на английский.

Использует те же семь файлов, preflight, смысловой ledger, калибровку, независимую QA и target-only чтение; языковой слой — английский. Глоссарий называется GLOSSARY_RU_EN. Права сохранять форму ради сюжетно значимого смысла и менять форму ради функции совпадают с общим контрактом.

Этот маршрут не является автоматическим обходом украинского канона. Если UA_CANONICAL_MASTER уже утверждён, обычный EN-процесс использует UK→EN. Прямой RU→EN возможен только при явном выборе автором такой отдельной редакции; его происхождение должно остаться видимым.
