# Спецификация скилла для Бюро

Предлагаемое имя: `ru-buro-series`. Назначение: писать, развивать и проверять «Бюро несостоявшихся миров» по конкретному тому и источнику, сохраняя различие знания, процедуры, моральной цены и подачи. Это спецификация для создания рабочего скилла; она сама не утверждает, что новый скилл установлен.

## Вход и маршрутизация

Сначала открыть `project.json`, `books/<id>/book.json`, выбранный мастер, `brief.md`, `voice.json`, `session.md`; затем `series/CANON-POLICY.md` и относящиеся факты. Для черновика применять `ru-book-writer`, для изменения подачи — `ru-book-voice`, для доказательного аудита — `ru-book-auditor`, для адресной правки — `ru-book-revision`, для структуры — `ru-book-architect`. Не заставлять каждый абзац проходить все методики.

## Правила серии

- Мастера трёх томов пока `candidate`. Не объявлять их финальными и не менять исходные байты при инвентаризации.
- WORLD — ранний замысел; рукопись уже конкретизирует Бориса и трилогию. Не сокращать 45 глав до 36 ради старого каркаса.
- Уважать три ступени: профессиональная эвакуация и прозрение; спуск в удержание; подход к перу и отказ. Не начинать каждый том заново с незнания первого.
- В сценах счёта иметь отдельные величины для квоты, физической ёмкости, прошедших створ, доставленных и удержанных. Числа из показаний и документов помечать как заявленные, а не автоматически истинные.
- Различать Свод-инспектор и Свод-регламент; `сводить` не является упоминанием персонажа.
- Сведения о метрополии сначала могут быть показанием Прасковьи или выводом Бориса. Сохранять прямые оговорки источника, не превращать их в авторскую аксиому.
- Не выдавать свободный отказ за уничтожение машины: в предоставленном финале машина продолжает работать.
- Характер Бориса сохранять через внимание и выбор. Не прописывать обязательную частоту шуток, метафор и коротких фраз. Индивидуальный профиль тома имеет приоритет над универсальным пресетом.
- Проверять лупу Бирнбаума, полотно, манифест, бумаги и подписи как материальные цепочки владения и знания. В текущем тексте есть непроверенные противоречия — см. очередь.
- Связь с «Утками» и Риоккой не установлена: не импортировать чужую физику по сходству тем.
- Маркеры `[хук: ...]` сохраняются в исходной версии. При поручении читательской редакции удалить адресно с журналом; не принимать их за часть доказанной художественной структуры.
- Не называть выборочное чтение полным аудитом. У каждого вывода должны быть источник, версия и точный фрагмент.

## Формат результата

Для сцены: новый текст, версия, изменения состояния и открытые допущения. Для аудита: доказательство → эффект для чтения → действие → зависимые места. Для редакции: старый текст → новый текст → причина → проверка последствий. Новое правило мира или развязка помечается предложением до явного решения автора.
