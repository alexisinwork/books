# Исходники и дословное разделение

В `originals` находятся три предоставленных файла без изменения байтов. Их имена, размеры и SHA-256 записаны в `../source-manifest.json`.

Омнибус разделён по трём явным заголовкам `# КНИГА ...`, а не по предполагаемому финалу или объёму. Вступление до первого романа сохранено в `omnibus-front-matter.md`. Служебные строки, эпиграфы, разделители, названия и отметки `[хук: ...]` остались там, где стояли. Мастера имеют статус `candidate`: факт получения рукописи не означает, что автор назвал её окончательной.

Реестр `omnibus-split.json` содержит точные диапазоны байтов и строк. Конкатенация вступления и трёх файлов `master.md` восстанавливает исходник побайтно. После начала редакторской работы такое равенство перестанет быть ожидаемым для новой рабочей версии: сначала сохранить исходный мастер в `archive`, обновить реестр происхождения и назначить новую версию явно.

Проверка из корня серии:

```sh
python tools/verify_sources.py
python tools/studio.py doctor
```
