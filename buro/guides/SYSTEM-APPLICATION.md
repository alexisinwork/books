# Как применяется исходная «Система работы с книгами»

| Решение методики | Реализация для Бюро |
|---|---|
| Один явно выбранный источник, а не «последний по расширению» | Каждый `book.json` хранит точный мастер, статус `candidate`, SHA-256 и диапазон омнибуса |
| Канон, замысел и трактовка раздельно | WORLD сохранён как ранний замысел; `canon.json` содержит ограниченные факты с якорями; спорные узлы в очереди |
| Полный аудит нельзя заявить по выборке | `analysis-coverage.json` отделяет 100% технического сканирования от выборочного смыслового чтения |
| Состояние героя и знания читателя не смешивать | `knowledge.json`, `end-state.json` и отдельно отмеченные внешние финальные вставки |
| Сначала причинность, затем числа/знания, затем язык | `series/release-plan.md`; ранняя очередь чисел, лупы и памяти перед сокращениями |
| Отзыв относится к версии, которую читали | Пустой реестр `feedback/feedback.json` ждёт настоящий отзыв с идентификатором версии; отзыв брата о Риокке сюда не перенесён |
| Голос защищают примеры, а не универсальные квоты | Три `voice.json` с собственным вниманием и ритмом, статус предложений |
| Правка должна быть точной и проверяемой | Очередь содержит фактические цитаты, эффект, следующее действие; художественные исправления не подменены советами о якобы изменённом тексте |
| Выпуск проверяется в читательском формате | `release/checklist.md`; текущий исходный Markdown не выдан за визуально проверенный DOCX |

Документ `Система_работы_с-книгами.docx` сохранён в `guides/originals`, когда доступен среди предыдущих результатов. Его текстовая проекция служит поиску, не восстановлению вёрстки. Библиография и сведения о ранее выполненном аудите Риокки внутри него остаются историческим контекстом; они не доказывают аудит Бюро.
