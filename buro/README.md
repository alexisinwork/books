# Бюро несостоявшихся миров

Рабочий проект завершённой по внутренней маркировке трилогии: **«Чистый лист»**, **«По раскладу»**, **«Перо без руки»**. Три рукописи выделены из предоставленного омнибуса без изменения байтов. Окончательность этой версии автором отдельно не подтверждена.

Начать: `START_HERE.md`. Результаты текущего прохода: `SOURCE-ANALYSIS.md`. Все замечания этого прохода — в `series/continuity-queue.json`; изменения художественного текста не внесены.

| Каталог | Назначение |
|---|---|
| `sources` | Все три исходника, вступление омнибуса и доказательство дословного разделения |
| `books/book-01` | «Чистый лист», 45 глав; рукопись, план по заголовкам, профиль, сцены и знания |
| `books/book-02` | «По раскладу», 43 главы; отдельная рабочая история и состояние |
| `books/book-03` | «Перо без руки», 45 глав; отдельная работа с финальным выбором |
| `series` | Общий канон с источниками, движок трилогии, словарь, очередь расхождений |
| `skills` | Пять переносимых рабочих скиллов; спецификация особенностей Бюро — `series/skill-spec.md` |
| `guides` | Рабочий цикл и применение исходной «Системы работы с книгами» |
| `tools` | Скрипты создания книги, проверки версий, извлечения, контекста и проверки копий |

Все главы проиндексированы технически; это **не полный литературный аудит 133 глав**. Полностью прочитаны WORLD и публикационный кит. Рукопись читалась выборочно на входах, переходах, раскрытиях и финале; точные участки и ограничения — в `series/analysis-coverage.json`.
