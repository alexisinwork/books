# Работать с Бюро

1. Выберите том в `books`. Прочитайте его `book.json`, `brief.md`, `voice.json` и `session.md`.
2. Сверьте исходник: `python tools/verify_sources.py`, затем `python tools/studio.py doctor`.
3. Для структурной работы возьмите `series/engine.md` и `plan.md` книги. Для новой сцены — только её соседей, затронутые факты и `knowledge.json`. Финальные знания третьего тома не подмешиваются в ранний внутренний голос Бориса.
4. Редакторскую работу начните с `series/continuity-queue.json`: числа, судьба Бирнбаума, механизм памяти и границы знания. После этого — повторы объяснений, служебные вставки и корректура.
5. Оригиналы не перезаписывайте. Для новой редакции скопируйте мастер в новый файл, внесите порученные изменения, запишите точный журнал, затем назначьте полученную версию мастером с причиной. Не назначайте найденный омнибус «последней версией» только потому, что он полный.

Команды из корня этой серии, Python 3.10+:

```sh
python tools/studio.py doctor
python tools/verify_sources.py
python tools/studio.py snapshot --book book-01 --allow-candidate
python tools/studio.py context --book book-01 --allow-candidate --task "Проверить числа в главе 1" --out sessions/book-01-numbers.md
python tools/studio.py compare-voices --book-a book-01 --book-b book-03
```

Проверка `doctor` сообщает о неподтверждённых мастерах и предложенных профилях; эти предупреждения ожидаемы. `--allow-candidate` разрешает исследование предоставленной версии, а не подтверждает её окончательность.

Если автор решит расширить трилогию новым самостоятельным томом:

```sh
python tools/studio.py new-book --id book-04 --title "Новый том Бюро" --profile custom --differentiation related
```

Новая книга начнётся с чистых файлов. Она не наследует готовую развязку, число спасённых или голос другого тома автоматически. Сначала потребуется решить, совместимо ли продолжение с уже написанным финалом трилогии.

## Украинский оригинал и языковые издания

Новый рабочий процесс: [BOOK_SYSTEM](../BOOK_SYSTEM/README.md), путь также задан в `project.json.book_system`. Новая книга создаётся на украинском; `new-book --language en` — явный английский оригинал. Русские файлы остаются историческими источниками. Для Риокки 1–3 сначала RU→UK, затем после авторского утверждения UK→EN; прямой RU→EN — отдельный зеркальный маршрут. Рукописи в ходе настройки системы не переводились. Литературный цикл требует Opus + Gemini 3.8 Flash + Gemini 3.1 Pro.
