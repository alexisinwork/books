# Профиль подачи

Минимальная запись: `profile_id`, `book_id`, `status` (proposed/approved/observed), `differentiation` (distinct/related/unspecified), `inherit_author_traits`, `axes`, `protected_examples`, `scene_overrides`, `revision_reason`.

| Ось | Рабочее решение |
|---|---|
| POV и время | Кто рассказывает, откуда знает, когда относительно события |
| Дистанция | Ощущение сейчас, позднее осмысление, наблюдение со стороны |
| Внимание | Что герой замечает первым; профессиональные и личные фильтры |
| Ритм | Развитие абзацев, ускорение и паузы; без квот слов |
| Синтаксис | Связность, эллипсис, уточнения, длинные периоды |
| Диалог | Недоговорённость, социальная разница, перебивания |
| Юмор | Источник комизма, кто понимает шутку, где она уместна |
| Образы | Откуда метафоры, насколько заметны, что рискует стать штампом |
| Экспозиция | Через действие, наблюдение, документ, прямое объяснение |
| Информация | Что знает читатель относительно героя; правила скрытия |
| Вход и выход главы | Как начинается движение и чем заканчивается внимание |

Для сравнения: «ось / книга А / книга Б / эффект». Сходство сознательного цикла разрешено. `distinct` вызывает обсуждение совпадающих решений, но не требует искусственной противоположности. Защищённые примеры — короткие авторские фрагменты с источником; личные данные автора не становятся инструкцией персонажам.
