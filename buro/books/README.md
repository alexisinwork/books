# Три тома Бюро

Каждая папка содержит собственный дословный мастер, профиль, план, состояния и журнал. Общий канон относится к миру, а голос и задачи остаются у конкретной книги. Книга не наследует знание из последующих томов автоматически.

`book-01` — «Чистый лист», `book-02` — «По раскладу», `book-03` — «Перо без руки».

Все мастера имеют статус кандидатов из одного предоставленного омнибуса. Их байтовую связь проверяет `tools/verify_sources.py`; полный литературный аудит этой проверкой не выполняется.
