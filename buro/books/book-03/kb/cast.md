## Борис
- **Функція:** фокус; аудитор нормативної влади; кандидат на розширений мандат.
- **Бажання:** зрозуміти, `точка, де конкретна пропозиція отримує силу правила` (розд. 1); далі — довести реформи; зрештою — межа власної ролі.
- **Арочні точки:** відмовляється від «одного лиходія» (розд. 1–2) → бачить ціну рекомендацій (3–5) → пам'ять: `Інституційне втручання було.` (15), `Він не читав.` / `Оце його частина.` (19) → `Система стара. Борис — ні.` (21) → два речення, Марія Лест (22) → вхід до Пера (23–24) → `— Мені добре.` (28) → `Частина мене дуже хоче.` (32) → `Він не брехав.` (39) → `Бо я можу бути тут добрим.` (40) → ціна (41) → accountable advisor (42) → `Незаповнений наступний рядок.` (44).
- **Голос:** сухий, короткі репліки, самоіронія на межі; гумор рідкий, гіркий: `Не заважайте мені ненавидіти.` (1); `Мені подобається, коли теорія стає менш злою й більш небезпечною.` (1); `Великий травмований прототип. Мені було нудно.` (20). Ризик: той самий ритм у всіх (див. editing-brief).
- **Не-герой [висновок]:** текст свідомо знімає з нього міф («нульовий», «триста років», «ланцюг»).

## Звід (RU Свод)
- **Функція:** інспектор-епістемолог; противага узагальненням Бориса.
- **Бажання:** `Закрити службову перевірку без неправди.` (1).
- **Арка:** догана (8) → новий статус «стан невідомий» → повний доступ повернуто, догана лишилась (43) → група архівного перегляду, 217 справ (44).
- **Голос:** «Так.» / «Ні.» / `Не моя графа.`; `— Інспектор.` (8); формулювання-відповіді: `«Що сталося, хто що знав, хто що міг змінити, і що ще можна виправити».` (2). Сухий гумор: `— Романтик.` (про нього, 1).
- **RU-різниця:** у RU «Свода списали», спалений рапорт; в UA — службова перевірка, стягнення, без спаленого рапорту [текст].

## Ярина (RU Веда — функціонально)
- **Функція:** незалежна свідка з власною справою (Рута); межа доступу для Бориса.
- **Бажання:** знайти/зрозуміти Руту, не ставши функцією: `Не робіть із мене функцію.` (7).
- **Арка:** їде (1) → ключ-токен і `DECLINED BY SUBJECT` (7) → `Ваш верхній аудит поки не потрібен.` (43) → персональна відповідь без обговорення (43) → `Дай тільки код.` / `Навчився.` (44).
- **Голос:** колючий, контроль меж: `— Змішуєте обличчям.` (1); `Ви ще думаєте, що якщо людина допомагає вам двічі, вона вже «ваша».` (7).

## Стах
- **Функція:** зв'язок; у т. 3 — виходить із ролі «голосу в вусі».
- **Бажання:** Майя, але без рішення за неї.
- **Арка:** зникає в зоні глушіння (15) → відмовляється йти з Борисом, бере роботу на передачах (16) → протокол «що оператор не бачить» (16) → `Частина мене дуже хоче.` → `Оце вже відповідь.` (32) → бачить Майю 20 хв (43).
- **Голос:** `— Не драматизуй.` (15); `— Ти зараз будуєш таке крісло, в якому сам готовий сидіти.` (39); `— Тебе тепер іноді не слухають.` (41).

## Майя
- **Функція:** тримачка сектору H-2; інший тип опору — зробити себе замінною.
- **Бажання:** `Якщо колись вийду, не хочу, щоб сектор розвалився через мій вихід.` (16).
- **Арка:** текст Стаху (16) → короткі внутрішні виходи → `Я хочу спробувати зовнішній вихід як окрема людина, не як тримач групи.` (43) → 20 хвилин: `— Не проси лишитись.` (43).
- **Голос:** сухий, з гумором: `Ніхто не помер. Дратує.` (16).
- **RU-різниця:** у RU «Майя вышла… держа его за руку» у фіналі; в UA — не виходить остаточно [текст].

## Старик / Держатель сороковий
- **Функція:** чинний держатель PEN-класу; «правий по корисності».
- **Бажання:** піти, але `Не було доброго наступника.` (25); потім `Бо я втомився.` (39).
- **Біографія [текст]:** кар'єра `Був локальним аналітиком.` (25); не автор P-0; `— Я не ваш батько.` (25); `Сумував за роботою.` (25); перше велике рішення `Двадцять із лишком років тому.` (25).
- **Арка:** зустріч (25) → колега-опонент (26–33) → пропозиція (32) → `Він не брехав.` (39) → власний «дрейф» (39) → лишається, `Дата рішення.` (42) → `Перо не здригнулося.` (44).
- **Голос:** рівний, визнає незнання, не захищається: `— Знайдете. Я людина.` (25); `— Це не суд.` (27); `Я можу не поважати, якщо вам легше.` (40).
- **RU-різниця (ключова):** у RU — «Я был тобой», «растил триста лет», «придумал доить», «перепиши себя»; в UA усе це знято або спростовано [текст]. Див. continuity §1.
