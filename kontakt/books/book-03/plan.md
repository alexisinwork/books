# План развития тома

Полный авторский костяк: `../../sources/originals/КОСТЯК-КНИГА-3-Контакт(1).md`. Его текст сохранён дословно; все 34 записи перенесены в scenes.json как планы.

1. Проверить относящиеся к этому тому решения из series/continuity-queue.json.
2. На каждую сцену уточнить цель, сопротивление, наблюдаемую цену, изменение знания и следующий шаг.
3. Написать связный черновик. Для первой сцены взять профиль этого тома.
4. Выбрать написанный файл командой set-master, сделать snapshot.
5. Проверить причинность, ограничения Резонанса, согласие участников и только затем строку.

Защищаемая выплата: Ося присваивает предсказанный выбор; Даль отказывается дочитывать свой файл.

Не подгонять готовые сцены под одинаковый номер шага Труби: 34 главы — исходный план, не обязательная длина.
