# CARRY-IN FROM BOOK 02

Перед любой работой над книгой 3 считать установленным:

- Даль: R2, дезертир, жив.
- Балласт рядом.
- Тарас — устойчивый друг / Якорь с собственной работой.
- Даль отказался быть брендом Однодневок.
- Однодневки не уничтожены; Вектор продолжает считать масштабирование решением.
- Лана признала проблему algorithmic discoverability.
- Ира не является обязательным сквозным персонажем.
- Нулевые сутки показали: убрать ranking недостаточно для создания связей.
- Технический cache показал pre-decision capacity reservation.
- Механизм этого reservation ещё неизвестен.
- Книга 3 не должна ретконить книгу 2 в «весь бунт был инсценирован». Он был реальным, но прогнозируемым.
