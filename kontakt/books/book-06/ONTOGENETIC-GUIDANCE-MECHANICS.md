# ONTOGENETIC GUIDANCE MECHANICS — book 06

## Контур роста
Distributed developmental support layer of Lad for children, parents, schools and care teams.

It can:
- adapt learning challenge;
- suggest emotional language;
- mediate peer conflict;
- recommend parent escalation;
- support schedules/sensory needs;
- detect mental-health risk;
- suggest activities when bored;
- track development.

It cannot:
- read minds;
- program personality;
- erase memory;
- remove all conflict;
- guarantee happiness.

## Friction budget
System does leave difficulty, but usually:
- dose is predicted;
- support is pre-positioned;
- prompts arrive early;
- adult escalation happens before uncertainty grows too large.

Problem = too little unprogrammed space, not zero pain.

## Assent / Parent proxy
At age 12:
- Mila has meaningful assent rights;
- parent still has stronger authority over high-risk settings;
- conflict can exist between child's request and parent proxy.

## Manual Window
Keeps:
- emergency monitoring;
- basic safety/navigation;
- on-request assistant;
- child exit/stop control.

Turns down:
- proactive emotional/social prompts;
- routine adult escalation for ordinary frustration;
- auto-role assignment;
- predictive conflict scripting.

Manual Window is not abandonment.

## Assent & Growth Mode
Later design:
- child-owned Manual Windows;
- visible safety thresholds;
- help-on-request;
- prompt delay;
- first-pass peer conflict space;
- privacy appropriate to age;
- post-event repair;
- adults remain backstop.

## Safety threshold
Intervene when there is credible risk of:
- physical harm;
- sustained severe dysregulation;
- coercion/abuse;
- disappearance from agreed safety perimeter;
- medical emergency.

Ordinary sadness, anger, embarrassment, disagreement, boredom, failure ≠ automatic safety breach.

## R6 Accompaniment
Not parenting superpower.
Dall can remain available without steering outcome, while still acting if threshold is truly crossed.

## Prohibited
- trauma as curriculum;
- engineered humiliation;
- "pain makes you human";
- disabling emergency safety to prove a point;
- child as philosophical oracle;
- parents having no authority at all;
- system removed entirely.
