# Збирання й перевірка робочих фаз

`assemble-working-volume.py` приймає лише повний послідовний комплект глав для явно названої фази. Первинний текст Astra, повний текст Terra і редакція Terra мають окремі незмінні збирання. Збирання не засвідчує літературної якості.

Перевірені спільні засоби містяться в `books/book-01/production/2026-09-21-book01/tools/`: `build-reader.py`, `render-docx.cjs`, `check-render.py`, `prepare-review-parts.py`, `run-prepared-review.py`. Для незалежного свіжого контексту Terra доступний `books/book-01/revisions/2026-09-23-integration/run-native-review.py`. Кожний запуск зберігає запитану модель, вхід, хеш і фактичну відповідь; успіх транспорту не є доказом повного читання.

Gemini запускається лише через agy. Pro одержує тільки рукопис і нейтральне літературне завдання. Чужі відгуки не включаються до жодного незалежного проходу. Для автора діє виняток щодо недоступного Opus; часткове читання не називається повним.

Застосування літературних навичок узгоджується з прямим новим дорученням: вся структура й усі чернетки перед повним письмом Terra, потім літературні проходи, звірка й остаточна редакція. Старий покроковий цикл Sol не повертається непомітно.
