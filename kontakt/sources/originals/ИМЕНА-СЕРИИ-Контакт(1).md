# ИМЕНА — серия «Разлад» (мир «Лад») — канон [ЗАКОН]

Единый источник правды. Резолвит все заглушки из костяков. Принцип: холодно/инженерно, переводимо (несущие имена без каламбуров — под перевод), тихий смысл под фамилией, русский бонус где бесплатен.

## Мир и система
- **«Лад»** — социальная ИИ-инфраструктура (Accord/Concord). Оставлено: тёплое, односложное, «зло, которое любит», переводимо.
- **Серия: «Разлад»** (EN: *The Discordant*). Отрицание «Лада» — и «разлад/раскол». В русском играет с «Лад» бесплатно; в переводе несёт как «Discordant».
- **Книга 1: «Контакт»** (EN: *Contact*). Оставлено.
- **Система прокачки: «Резонанс»** (EN: *Resonance*). Оставлено.
- **Класс/идентичность:** официально — *дискордант*; на улице/в подполье — *разлад*.
- Термины оставлены: «Однодневки», заглаживание, Балл Совместимости.

## Герой
- **Марк Даль** (EN: *Mark Dahl*). Мостом — обычно зовётся по фамилии, **Даль** (холодно, дистанция — «даль», тот, кто держит всех на расстоянии; пасхалка для рус. читателя — Даль-лексикограф, «калибровщик значений»). Подполье зовёт его **«Разлад»**. Бывший лучший калибровщик, дискордант.

## Компаньон (нежеланный ИИ)
- Присвоенное «Ладом» сахарное имя: **«Ладушка»** (уменьшительное от «Лад» + «ладушки-ладушки» — жутко-умильно; система-любовь в миниатюре).
- Как зовёт его Даль: **«Балласт»** (мёртвый груз, который тащит; инженерный цинизм — и тематически это и есть комфорт-балласт). EN: *Ballast*.

## Найденная семья (копится по томам — рост «Резонанса»)
- **Тарас** = «Якорь» (кн.2; первый живой якорь; гибнет кн.5). Так его зовёт Даль. Мужская дружба, не роман — свежее и точнее по теме (близость ≠ роман).
- **Ося** (Осип) = «Беглец» (кн.3; спасённый отклонившийся, дальше спутник).
- **Мила** = «Дитя» (кн.6; идеальный ребёнок, что видит полость Даля насквозь). «Мила» — «милая», мягко и иронично против пустоты.

## Противник-зеркало (рекуррентный)
- **Тихон** = «Безмятежный» (бывший наставник Даля по калибровке, ушедший в комфорт). Имя от «тихий» — тот самый безмятежный покой; реальное рус. имя, переводится как имя.

## Пооконные противники и каст
- Кн.1: **Гор** = «Заказчик» (контролирующий клиент; короткое, твёрдое). **Майя** = угасающая клиентка (оставлено).
- Кн.2: **Вектор** (лидер «Однодневок»; хэндл — направление/драйв, подполье живёт хэндлами). **Лана**, персона **«Витрина»** (фигура в идеальном фокусе, инфлюенсер-витрина внимания).
- Кн.3: **Эмиль Лоц**, прозвище **«Лоцман»** (архитектор Predictariat — «лоцман», ведущий по колеям-траекториям; прозвище из фамилии).
- Кн.4: **Рем Ковач** = «Оценщик» (бывший равный Даля-калибровщик, поднявшийся по метрике; личный соперник). **Эдит** = «Списанный» (женщина-избыток, интернализировавшая никчёмность).
- Кн.5: **Влас** = «Сборщик» (сломанный сообщник — бывший носитель, ставший оператором слива). **Аста** = «Носитель» (несёт чужую боль осознанно, живее всех).
- Кн.6: **Марта** = «Садовник» (архитектор форсированного онтогенеза; горюющая мать-логика). **Ждан** = «Родитель» (трагический заказчик; имя «Ждан» — «жданный/долгожданный» — родитель, горюющий по не-случившемуся ребёнку).
- Кн.7: противник без лица — «Согласие»/коллектив; арку закрывает **Тихон**. Новых имён не требует.
