# Протокол адресной правки

Вердикты: подтверждённая ошибка; ответ есть, но плохо считывается; недостающая причинная связь; предпочтение. Возможен смешанный вердикт.

Единица правки: source_sha256 + глава + точный якорь + действие (заменить/вставить/удалить/перенести) + новый текст + причина + зависимости. При переносе указать исходные границы и нового адресата знания.

Защита голоса: выписать 3–5 действующих черт из текста. Сравнить до/после по ним. Не называть текстовую оценку ритма аудиочтением. Не запрещать антитезы глобально и не делать всех персонажей одинаково афористичными.

Защита причинности: счётчик не должен исключить погибшего из исходной группы; технология не должна обнулить прежние угрозы; знание требует источника; мотив противника не заменяет пределы его возможностей.

Проверка: открыть итоговый читательский файл, подтвердить принятые правки, проверить зависимые сцены, обновить конец тома в справочнике. Выгрузку перегенерировать из мастера. Не повторять полный аудит после одной запятой без конкретной причины.
