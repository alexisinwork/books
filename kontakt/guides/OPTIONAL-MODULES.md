# Чем расширять систему по необходимости

| Задача | Что подключить |
|---|---|
| Детектив | Реестр улик, ложных версий и доступности сведений |
| Боевая или дорожная сцена | План пространства, длительности, ранения, вещи |
| Большая серия | Состояние после каждого тома, календарь, зависимости раскрытий |
| Несколько рассказчиков | Профили POV и границы знания каждого |
| Психологическая история | Дилеммы, защита, привязанности, поведение под давлением |
| Роман отношений | Карта изменения доверия, дистанции и власти |
| Нефикшн | Тезисы, источники, аргументы, возражения и границы применимости |
| Мемуар | Память / документы / восстановленная сцена; согласованные имена |
| Издание | Синопсис, аннотация, метаданные, корректура, макет и журнал выпусков |
| Перевод / аудио | Термины, произношение, голоса, адаптации и версия оригинала |

У каждой подключённой формы должен быть практический вопрос. Если форма перестала помогать, архивируйте её. Медицинские, исторические, правовые и научные утверждения исследуйте по источникам; психологический шаблон не заменяет диагностику реальных людей.

Новые модули добавляйте в templates и описывайте в project.json. Не превращайте всю библиотеку методик в обязательный промпт на каждую сцену.
